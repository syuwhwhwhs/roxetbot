# 🚀 RoXeT BoT

![RoXeT BoT preview](preview.png)

**v0.2.18** — ربات فروش و پنل مدیریت برای **PasarGuard**

فروش اشتراک، نمایندگی، کیف پول و عملیات پاسارگارد؛ رابط ربات فارسی، پنل وب روی پورت `9000`.

> ⚠️ **نسخه بتا** — امکان وجود باگ در این نسخه هست. برای محیط حساس با احتیاط استفاده کنید.

## ✨ قابلیت‌ها

### 💳 فروش و پرداخت
- پلن‌های کاربر و خرید مهمان
- کیف پول، کارت‌به‌کارت، درگاه، رمزارز، استارز
- تمدید، سرویس‌های من، هشدار انقضا و حجم
- تمدید خودکار و افزایش خودکار زمان/حجم از کیف پول، با انتخاب جداگانه برای هر سرویس

در «سرویس‌های من ← تنظیمات خودکار» (یا مینی‌اپ)، پلن تمدید و بسته‌های افزایش
زمان/حجم را انتخاب و فعال کنید. سرویس‌ها هر دقیقه بررسی می‌شوند؛ بستهٔ فعال برای
مورد تمام‌شده اولویت دارد و تمدید کامل جای زمان و حجم را با پلن انتخابی پر می‌کند.
هزینه با قیمت فعلی از کیف پول همان فروشگاه کسر می‌شود. موجودی ناکافی، خرید را
تا شارژ کیف پول متوقف می‌کند. حذف یا غیرفعال شدن گزینهٔ انتخابی با پیام انتخاب
جایگزین به کاربر اعلام می‌شود. سفارش با نتیجهٔ نامشخص برای بررسی پشتیبانی نگه
داشته می‌شود و خرید خودکار دوباره انجام نمی‌شود.

### 🏪 نمایندگی
- پلن و فروشگاه نماینده
- سهم / PAYG، ربات اختصاصی
- مدیریت نمایندگان از وب و بات

### 🛡️ پاسارگارد
- کاربران، ادمین، گروه، هاست، نود، تمپلیت
- سهمیه و نقش زنده از پاسارگارد
- ساخت کاربر از تمپلیت یا سفارشی

### 🖥️ پنل وب
- داشبورد، سفارش‌ها، تیکت، تنظیمات
- راهنمای درون‌پنل (`/help`)
- مینی‌اپ تلگرام (اختیاری، HTTPS)

## ☁️ استقرار روی Railway

1. پروژه را در یک ریپوی GitHub (ترجیحاً خصوصی) push کنید.
2. در Railway: **New Project → Deploy from GitHub repo** — فایل‌های `Dockerfile` و `railway.json` خودکار شناسایی می‌شوند.
3. در همان پروژه: **New → Database → Add PostgreSQL**.
4. روی سرویس برنامه → **Variables**، مقادیر فایل [`.env.railway.example`](.env.railway.example) را وارد کنید
   (`PORT=9000`، `BOT_TOKEN`، `ADMIN_IDS`، `PG_*`، `WEB_ADMIN_PASSWORD`، `WEB_SECRET` و `DATABASE_URL=${{Postgres.DATABASE_URL}}`).
   `WEB_SECRET` را حتماً دستی و ثابت بگذارید؛ با تغییرش رمزهای ذخیره‌شده قابل خواندن نمی‌مانند.
5. **Volumes → New Volume** با مسیر mount برابر `/app/data` (بدون Volume، رمز پنل و بکاپ‌ها با هر دیپلوی پاک می‌شوند).
6. **Settings → Networking → Generate Domain** تا آدرس عمومی `*.up.railway.app` ساخته شود.
7. دیپلوی را اجرا کنید؛ پنل روی `https://<دامنه>/` بالا می‌آید و با `WEB_ADMIN_USER` / `WEB_ADMIN_PASSWORD` وارد می‌شوید.

**نکات**
- چون اطلاعات از Variables خوانده می‌شود، ویزارد `/setup` لازم نیست.
- پورت (`PORT`)، دامنهٔ عمومی و حالت پروکسی به‌صورت خودکار تنظیم می‌شوند؛ HTTPS را خود Railway می‌دهد.
- متغیرهایی که در Railway ست کرده‌اید بر مقدارهای ذخیره‌شده از داخل پنل اولویت دارند؛ برای تغییرشان از Variables استفاده کنید.
- آپدیت از داخل پنل غیرفعال است: تغییر را به GitHub push کنید تا Railway دوباره دیپلوی کند.
- حالت webhook اختیاری است: `WEBHOOK_URL=https://${{RAILWAY_PUBLIC_DOMAIN}}` (پیش‌فرض: long-polling).
- فقط یک نمونه (replica) از سرویس اجرا شود.

## 🚀 نصب روی VPS (اختیاری)

**منابع پیشنهادی:** ۲ گیگ رم و ۲ هسته CPU · Ubuntu 22.04+

### قبل از نصب این‌ها را آماده کنید
1. **دامنه** متصل به آی‌پی سرور
2. **توکن ربات**، **یوزرنیم ربات** و **آیدی ادمین** تلگرام
3. **اطلاعات ورود پنل پاسارگارد** (آدرس، یوزر، رمز)

> ⚠️ آدرس‌های نصب‌کننده (`get.sh` و `roxet.sh`) هنوز به ریپوی اصلی `Mrclocks/PGClockBot` اشاره می‌کنند. بعد از push پروژه در ریپوی خودتان، این آدرس را با ریپوی خودتان عوض کنید (یا `ROXET_REPO` را ست کنید)، وگرنه نسخهٔ بدون برند RoXeT نصب می‌شود.

### یک‌خطی
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Mrclocks/PGClockBot/main/get.sh)
```

بعد از نصب، راه‌اندازی در مرورگر کامل می‌شود: `http://SERVER_IP:9000/` (یا دامنهٔ شما).

### منوی اسکریپت (`roxet.sh`)
دستور بالا منو را باز می‌کند. داخل پوشهٔ پروژه هم:

```bash
bash roxet.sh
```

| گزینه | کار |
|------|-----|
| `1` Install | نصب خاموش → ادامه در ویزارد `/setup` |
| `2` Update | به‌روزرسانی کد (`.env` حفظ می‌شود) |
| `3` Edit .env | ویرایش توکن / پنل / پورت |
| `4` Web panel | آدرس پنل، ریست رمز، health |
| `5` Service | وضعیت / استارت / ری‌استارت / لاگ |
| `6` Status | خلاصهٔ سلامت |
| `7` Uninstall | حذف کامل |
| `0` Exit | خروج |

میانبر بدون منو:

```bash
bash roxet.sh install
bash roxet.sh update
bash roxet.sh status
bash roxet.sh help
```

## 🛠️ CLI سراسری (`roxet`)

بعد از نصب (یک‌بار با sudo):

```bash
sudo bash scripts/install_global_cli.sh
```

از هر مسیری:

```bash
roxet status
roxet start
roxet stop
roxet restart
roxet logs              # ۱۰۰ خط آخر
roxet logs -f           # دنبال کردن لاگ
roxet health
roxet backup --note "pre-update"
roxet backup --list
roxet restore <backup_id> -y
roxet migrate
roxet doctor
```

بدون نصب سراسری، از ریشهٔ پروژه:

```bash
export ROXET_HOME=/path/to/RoXeT BoT
./scripts/roxet status
```
